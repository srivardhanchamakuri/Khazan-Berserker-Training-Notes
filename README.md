## 📖 Overview

Welcome to the **Khazan Ashen Archive**, a meticulously engineered training companion designed for players who want to sharpen their instincts, master pacing, and explore the deep mechanical layers of *The First Berserker: Khazan*. This repository is not just a utility — it is a philosophy. It treats every session as a rehearsal, every boss as a mentor, and every death as a data point worth studying.

Where most tools hand you blunt advantages, the Ashen Archive instead offers a *lens*. It reframes the brutal, beautiful rhythm of Khazan's combat into something you can observe, annotate, and internalize. Think of it as a training dojo carved out of obsidian — silent, precise, and rewarding to those who return to it daily.

This project supports Windows 10 and Windows 11 and is maintained actively throughout the 2026 release cycle.

---

## ✨ Why the Ashen Archive Exists

The First Berserker: Khazan is a game of consequences. A single mistimed parry spirals into a chain of ruin. A misread stamina bar turns a victory march into a death spiral. Most players learn through repetition alone. The Ashen Archive accelerates that learning loop by giving you a structured mirror to practice against.

Instead of brute force, it offers *deliberate rehearsal*. Instead of shortcuts, it offers *clarity*. The project was born from hundreds of hours of community feedback, spreadsheets, frame notes, and late-night theorycrafting among players who love the game enough to want to understand it fully.

- Multiple profile slots tailored to different bosses or builds.

## 🧭 How to Think About the Archive

This is a tool for *students of the game*, not just players. The distinction matters.

- A player asks, "How do I win this fight?"
- A student asks, "Why did I lose that exchange?"
- The Ashen Archive answers the second question, then quietly hands you the tools to answer the first.

Treat every session as a lesson. Treat every mistake as a syllabus entry. Treat the archive as a place you return to, not a place you escape from.

## 🏗️ Project Architecture

The repository is organized into logical modules, each with a focused reason to exist.

- **/core** — The rehearsal engine, session state, and event dispatcher.
- **/profiles** — Profile schemas, migration logic, and example templates.
- **/analytics** — Aggregation, visualization data-formatters, and export utilities.
- **/ui** — Responsive layout definitions, themes, and locale bindings.
- **/locales** — Community translation files and review guidelines.
- **/docs** — Extended documentation, tutorial narratives, and design notes.
- **/tests** — Behavioral regression suites, fixture data, and stress scenarios.

Each module is designed to be independently testable, so contributors can iterate without dragging the whole project through a rebuild.

## 🧪 Quality Commitments
